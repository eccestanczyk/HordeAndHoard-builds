# Horde & Hoard: test builds

Packaged test builds of the game Horde & Hoard for Windows. Downloads only: this repository holds no source code.

## Install

1. Download [HordeAndHoard-Test.zip](https://github.com/eccestanczyk/HordeAndHoard-builds/releases/latest/download/HordeAndHoard-Test.zip).
2. Unpack it into a folder of your own (not "Program Files").
3. Start `HHLauncher.exe`. The first start downloads the game (about 2.5 GB) and starts it. Later starts fetch only what changed.

The launcher is not signed yet: Windows SmartScreen may say "Windows protected your PC". Click "More info", then "Run anyway".

The other files of a release are the game's files, fetched by the launcher. You do not need to download them by hand.
